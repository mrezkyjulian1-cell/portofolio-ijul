# Portofolio - Muhammad Rezky Julian (Ijul)

Modern, responsive, and interactive personal portfolio website built with React, Vite, and Tailwind CSS.

## 🚀 Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + Custom CSS Animations
- **Icons:** Lucide React
- **Design:** Glassmorphism, Dark Neon Cyber-Aesthetic, Smooth Scroll & Splash Screen

## 📦 Features

- 🌟 Futuristic Hero section with interactive CTA
- 👤 About Me with personal story and background
- 🛠️ Tech Stack & Skills with interactive category filtering
- 💼 Projects Showcase with interactive modals, live links, and GitHub repositories
- 📜 Experience & Education timeline
- 📬 Contact Section with direct messaging integration
- 📱 Fully responsive across Mobile, Tablet, and Desktop screens

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mrezkyjulian1-cell/portofolio-ijul.git
   ```

2. Navigate into the project directory:
   ```bash
   cd portofolio-ijul
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
